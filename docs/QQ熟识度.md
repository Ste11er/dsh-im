# QQ 熟识度

本项是仓库借鉴清单的第一个集成功能，已部署并在当前测试机器人启用。它只计算熟识度，不实现好感度；后续功能在本项用户测试确认后继续。

## 使用与测试

在「设置 → IM机器人 → QQ 机器人设置 → 熟识度」选择启用或关闭。选择后立即保存，对后续回复生效。可点「查看／刷新熟识度」查看每页 20 条的成员记录、分数、档位、活跃天数和直接互动天数；「清除此人」经界面确认后删除对应会话里的这份计数，下次互动重新开始。清除不删除原群会话或长期记忆。

默认关闭；当前机器人的测试实例由本次部署启用。从启用后开始统计，不导入历史，不伪造认识天数。群与私聊分别记录；同一成员在不同群也分开。被 @ 的普通聊天和未 @ 的主动接话共用当前群 Session，回复只得到当前真实发言者的短状态。未 @ 的群消息只有通过既有访问策略并进入已启用的群聊上下文时才计数；权限拒绝、机器人自身消息与过期背景事件不计入。直接回复路径在通过既有命令处理后记录普通聊天，不为控制命令累积接触。

建议实群测试：

1. 自己 @ 她说「大肥鱼，我们现在熟不熟？」；随后不 @ 自然聊天，检查是否正常承接，同群会话没有改变。模型不必每次主动报分。
2. 点「查看／刷新熟识度」确认出现自己的记录；同日继续发多条，活跃天数仍为 1，直接互动天数最多为 1。
3. 另一位获准成员聊天后出现独立记录。昵称相同不能合并；其他群和私聊不能借用本群关系。
4. 关闭后聊天，再查看，确认天数不再累积；重启后已有计数保留。单人清除仅影响选择的记录。
5. 跨北京时间自然日再互动，活跃天数增加；熟识需要多日累积，本次不通过直接改分伪装成熟人。

自己的消息已经接收不等于模型一定主动接话。原有语义判断、冷却、忙时丢弃和发送控制仍然生效。

## 数据与候选曲线

每个 bot 使用独立 `bots/<botId>/familiarity.sqlite`，文件权限 `0600`。只保存会话/成员身份、可选昵称、首次/最近接触时间和每日是否直接互动，不保存消息正文或图片，不调用云端模型。采用 SQLite 事务更新成员与日记录；每日主键避免重复事件或刷屏增加活跃天数。日期统一按 `Asia/Shanghai` 计算。

设活跃天数为 D，直接互动天数为 M：

```text
familiar = min(1, 0.28 × log10(1+D) + 0.15 × log10(1+M) + 0.02)
floor    = min(0.6, 0.15 × log10(1+D))
tauDays  = 3 × (1+D/10)
strength = floor + (max(familiar,floor)-floor) × exp(-离开天数/tauDays)
score    = round(100 × strength)
```

档位：strength ≥ 0.7 为「熟悉」，≥ 0.4 为「眼熟」；其余在多日接触后显示「有过接触」，仅一天则为「刚认识」。当前消息到达会更新最近接触时间；久别时分数缓慢回落并保留旧相识下限。这是参考上游后按“每日接触”调整的候选产品曲线，不是心理学测量；没有照搬按消息数增加熟悉程度、好感评分或思考情感分类。45 天每日直接互动的模拟测试可达到熟悉，不代表本机成员已拥有这些历史。

关闭停止采集和回复注入，保留已有计数供管理查看。删除机器人时，在运行时停止之后删除对应数据库及 WAL/SHM 文件。没有自动数据过期或人数淘汰；每日记录会随真实活跃天数增长，需要按本地数据策略备份或通过管理入口清除。备份运行中的 SQLite 时应使用一致性备份或停机后连同数据库状态保存，不能只随意复制正在写入的主文件。

## 上下文与权限

只在当前可信 QQ delivery context 中携带本回合的数字状态，宿主提示不插入昵称或成员原话。短状态指导自然称呼、接梗和关心，不机械报分、不否认原会话记忆、不强行装亲密。它不是好感度，也不影响电脑命令、群管理或 owner 身份。

熟识度短状态小于 512 UTF-8 字节；在带长期记忆总览的被 @ 回复中，从原有 1200 字节总览预算中扣除其实际字节数，二者合计不超过 1200。细节查询仍走原有 `dsh_qq_memory`，保持其 3072 字节查询预算。没有开启长期记忆时只提供短状态，不偷偷启用归档。主动接话独立判断器不继承此人格/关系提示，实际回复在原群 Session 中使用关系状态。

本地存储失败会保留错误状态并记录本地诊断，聊天继续运行；不能把错误档案解读成空档案或初次相识。模型不能设置、提高或删除自己的熟识度，也没有新增可供群友操作本机的工具。

## 接口与实现

管理入口复用已有认证管理 RPC（`/qq`），不添加公开无认证入口：

| 端点 | 参数 | 结果 |
|---|---|---|
| `bot.familiarity.set` | `{botId, enabled:boolean}` | 常规脱敏状态；保存 `familiarityEnabled:true`，关闭时移除该字段 |
| `bot.familiarity.list` | `{botId, offset?:非负整数}` | 最多 20 条记录及 `nextOffset`；标识使用不可逆编号，显示名称只带平台身份尾号 |
| `bot.familiarity.clear` | `{botId, id:64位十六进制编号}` | `{removed:boolean}`；只操作该 bot 对应记录 |

普通状态只带开关、记录数和错误，不返回成员列表。手动凭据重绑、同应用扫码重绑保留熟识度开关，身份映射继续使用既有会话范围和独立 owner 校验。
