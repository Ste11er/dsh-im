# QQ 群聊表情包

QQ 设置卡片提供“群聊表情包：让 Agent 按语境选择 DeepSeek 表情回复”开关。每个机器人独立保存，默认关闭，重新扫码和重启保留设置。开启后，机器人在已有权限允许的被 @ 群回复中自行判断是否配表情、使用哪张图。无需换模型或开启长期记忆，也不会因为收到普通群消息而主动插话。

首次测试可在群里 @ 机器人说：“我今天很开心，用一张合适的表情包回应我。”确认真实图片发送后，再正常聊天观察自动选图的时机。Agent 可以决定不配图，不会每条强制发送；实际时机和选图质量需要结合群内使用评估。

## 公开目录与本地缓存

来源是[蓝色大肥鱼的 DeepSeek 页面](https://xn--pssy23gqgbz2d718b.com/characters/deepseek.html)。页面直接请求返回 403，因此程序使用该站公开链接的[源仓库](https://github.com/lmy414/bluedafeiyu)的 `data/works.json` 与三份 `blue-fish-*` 编辑清单，不依赖 HTML 布局。

- 只同步公开发布、角色为 DeepSeek、分类为 meme 的条目，合并历史表情，排除隐藏/删除条目和其他插画。
- 回复使用本地目录和已缓存原图，不访问远端目录、不启动后台同步。维护脚本检查 24 小时时效并刷新目录，四份清单固定为同一个 commit。新增表情需先运行预下载脚本。
- 可执行 `node scripts/prefetch-qq-stickers.mjs` 将当前全部公开 DeepSeek 表情下载并验证到本地；可选第一个参数指定表情缓存目录。按当前附件下载大小设置、4 路并行，报告全部条目的成功/失败，失败时退出非零；重复执行复用已验证缓存，可用于补充新增条目。不会自动向群发送图片。Agent 搜索情绪/场景获得最多 8 个候选；已缓存候选直接带校验后的本地路径和摘要，选中后直接回传，不再先调用 get。搜索只返回已缓存且校验通过的候选；未缓存条目不参与选图。
- 缓存默认位于 `~/.dsh/integrations/dsh-qq/stickers/`，跟随 QQ `dataDir`。目录、图片与元数据持久保存。旧目录可在网络失败时继续使用，工具结果明确标记陈旧缓存；首次同步失败则报错。
- 图源限定为该站发布的两个公开原图仓库，拒绝任意 URL 和跳转。历史档案图源在 `b498c80` 重命名了哈希文件；分类清单仍使用旧路径，因此原图固定到已核验包含全部 136 张历史表情的 `0d40d228a45410c153c23d733285b84b45856a1f` 版本，旧本地目录自动迁移。下载沿用附件设置的原图大小上限；校验格式和 SHA-256。投稿图同时核对发布摘要，缺少发布摘要的历史图仅记录本次下载摘要，不伪称具有上游完整性证明。
- 目录描述视为不可信内容，不执行其中指令。工具记录包含条目 ID、来源页、许可字段、原图地址和文件摘要，未知作者/许可仍保留未知状态。

## 回复链路与边界

`dsh_qq_sticker({query})` 搜索并返回可用的本地缓存路径；`dsh_qq_sticker({id})` 也仅读取本地缓存，缺少图片时明确报告未缓存，Agent 改用其他已缓存表情或文字。上述操作均未发图，Agent 还需调用现有 `dsh_im_return_file({path})`。文件在工具成功结果确认后绑定到当前 Session/Turn，交给已有 QQ 原生图片接口，保留原发送回执与不确定结果处理。不从模型正文解析文件路径自动发图，也不能通过表情工具指定其他收件群。

表情工具的执行与提示只对开启开关的当前 QQ 群回复生效，依据渠道传入并绑定到真实 Turn 的元数据判断；私聊、其他渠道、网页会话和已结束的回合不能使用。开关修改对后续回复生效，已开始的回复继续使用开始时的设置。普通文字问答、owner 命令权限和群聊访问策略保持原规则。

表情使用提示鼓励 Agent 主动选图：以当前频率为基础提高约 50%，在接梗、吐槽、赞同、感谢等适合的语境中优先考虑表情，也允许只用表情回复。

本功能不生成长期记忆、不修改长期记忆开关。图片目录与聊天记忆分别存储。

## 表情使用偏好

按用户最新反馈，目标为相对当前频率约增加 50%（约 1.5 倍），不是每条回复 50% 的随机发图概率，也不是增加 50 个百分点。适合的场景主动搜索表情，不需要用户明确点图或先征求同意；文字和表情都合适时优先表情。可以短句配图，也可以只发表情。没有贴切图片或需要认真解释时使用文字。

这是模型的行为目标，当前没有固定概率控制或实测旧频率基线，无法据此保证实际群聊恰好增加 50%。需在后续聊天中观察。不开启未 @ 主动插话，不修改人格正文和长期记忆。


## 回复速度

全量预下载减少首次原图下载等待；搜索直接给路径将常见“搜索→获取→回传”缩短为“搜索→回传”，减少一次模型工具往返。回复期间不更新目录，保留 stale/warning 标记。原图大小和完整性检查不省略，出站仍须可信回传工具登记后走 QQ 原生上传。

模型推理、多轮生成、QQ 图片上传仍会耗时。独立判断模型只影响未 @ 自主接话；选择独立判断后，批准接话需要判断与回复两次模型调用。可在界面选择更快的判断模型和聊天模型/思考强度，按质量与延迟取舍。缓存优化不会擅自更改模型、思考强度或聊天记忆设置。


当前回复策略为“仅本地缓存”：即使目录过期、网络可用或本地没有匹配图片，表情工具也不下载图片。没有合适缓存时用文字回复。源图预下载只由维护脚本执行，QQ 正常发送图片仍需上传至 QQ 平台。


## 梗鲸来源与空闲补库

新增来源为 [梗鲸 aigengtu.com](https://aigengtu.com/) 的公开 `gallery-index.json`，当前含 2430 个去重编号，按用户要求包含全部 AI 角色类别。保留站点标题、中文场景说明、作者贡献字段与来源页，未知许可保留 unknown。图片仅接受索引中的 `https://img.aigengtu.com/meme/编号.png|jpg|gif|webp` 原图，拒绝其他域名、查询参数和跳转。

`node scripts/prefetch-qq-stickers.mjs --aigengtu` 同步该站索引并下载全部当前条目，保留原来的 446 张。新索引单独存为 `aigengtu-catalog.json`，与旧目录合并搜索；重复编号/URL 去重，缓存图按文件摘要复用。

回复时仍为仅本地缓存。搜索没有候选会自动记录缺图关键词；有候选但不贴切时，Agent 调用 `dsh_qq_sticker({missing:"情绪或场景"})` 主动登记，然后先用文字回复。登记只保留简短场景、次数、状态、时间与下载计数，不保存原群消息或群成员身份，不调用额外模型。

缺图记录保存在表情目录的 `missing.json`。所有 QQ 消息处理（含实际回复投递）结束后，连续空闲 30 秒才启动补库；逐个查找原来源与梗鲸当前目录中尚未缓存的匹配条目并下载。新 QQ 消息到达会中止后台网络工作，让前台回复优先；保留 pending 状态，下一次空闲继续。Host 关闭时取消任务，重启将未完成 running 恢复为 pending。

记录状态区分 pending/running/done/not-found/failed。not-found 表示当前目录没有新的可下载匹配，记录保留；网络/源更新失败标记 failed，保留错误与已下载数量。重复缺图反馈会增加次数并重新排队。若所有源图都已缓存，补库不会重复下载，也不虚构站外新图。补库仅维护本地资源，不向群补发图片，也不回补已经结束的回复。
