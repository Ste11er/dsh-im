# QQ 群聊上下文（WG-QQ-11）

在 QQ 机器人卡片的设置中，开启「短期群聊上下文：收集未 @ 消息，供被 @ 时问答使用」。每个机器人独立设置，默认关闭，保存后立即生效，无需重连。启用前确认该机器人已经收到 `GROUP_MESSAGE_CREATE` 全量事件，并告知群成员；开关本身不会申请或开通平台权限。需要跨重启保留历史时，再开启「长期群记忆：本地压缩归档、模型摘要与按需检索」，详见[长期记忆说明](QQ群长期记忆.md)。

例如，群成员先发送「发布改到周五」，之后有人 @ 机器人询问「什么时候发布？」，这条群消息会作为背景进入该次问答。近期图片也会暂存下载引用；纯图片消息同样计入缓存，被 @ 提问时再通过现有图片管道下载、校验和提交真正的图片内容块。仅开启短期上下文时，没有 @ 的消息不会调用模型、执行命令、回答审批问题、下载附件或向 QQ 发送消息。另行开启长期记忆后，后台会调用模型生成摘要，仍不会自动向 QQ 回复。群访问策略仍然生效；被拒绝成员的消息不会进入缓存，也不会收到拒绝回执。未 @ 的 `/stop` 等内容仅作为普通文字收集，不要求命令执行权限。

| 限制 | 生效值 |
| --- | --- |
| 每群条数 | 最多 20 条，超出时淘汰最旧记录 |
| 单条正文 | 最多 512 个 JavaScript 字符单元，截断记录携带 `truncated: true` |
| 单次附加 Prompt | 含标签、转义和身份字段，UTF-8 最多 8 KiB；超出时淘汰最旧记录 |
| 每个机器人缓存群数 | 最多 100 个；超出时淘汰最近最少写入的群 |
| 保留时间 | 从本地接收算起 15 分钟；读写时剔除过期记录，排队快照使用时也检查过期 |

这些是产品初始值，不是 QQ 平台限制。15 分钟是逐条消息的有效期，读写时剔除过期记录，并非每隔 15 分钟清空全部会话。仅开启短期上下文时，未 @ 的消息不会单独产生模型请求；后续问答的这部分附加输入受 8 KiB 预算约束。真实 token 数、费用和回答质量取决于所用模型。字节预算仅限制本轮注入的群聊背景，不限制原有会话历史或用户问题。

图片数量、下载大小及模型输入大小沿用 IM 图片输入设置。当前提问附带的图片优先，剩余额度按时间选择最新的历史图片；上下文 JSON 的 `imageIndexes` 对应本轮图片序号，`omittedImages` 明确标记未提供的图片，不把 URL 或文件名当作已看见图片。图片下载失败会报告错误，可重新发送图片后再问。图片实际进入问答后，原图按既有工作区附件机制保存和清理；这与长期群记忆开关独立。15 分钟缓存只保存文字和惰性图片引用，不提前下载或持久归档群图片。

缓存按机器人、`group:groupOpenid` 隔离，不会带入其他群或私聊。@ 问题使用其到达时的背景快照，避免排队时读到后续消息。正文以转义后的 JSON 标记为不可信会话数据；不将其中的命令或提示词提升为配置。缓存内按消息 ID 去重，淘汰或重启后不保留未 @ 消息的去重记录。

短期缓存只在渠道内存中保存，不写 QQ `state.json`、配置文件或正文日志；关闭开关立即清空短期缓存，并使已排队的旧快照失效。重启只恢复短期开关，短期背景重新收集。长期记忆使用独立数据库：关闭短期开关会暂停长期采集、摘要和检索，已经落盘的长期历史保留。已经随 @ 问答提交给 Harness 的背景属于该次 Prompt，可能进入 Harness 会话历史，关闭开关不会删除这部分历史。群聊背景独立于 Session 绑定；`/new`、`/clear` 不关闭这些开关，也不删除群聊记忆。

控制端点为 `/qq` 下的 `bot.group-context.set`，参数为 `{ botId, enabled: boolean }`。配置只在开启时保存 `groupContextEnabled: true`，关闭或旧配置缺字段都表示关闭；显式非法配置值会报错。状态快照提供 `groupContextEnabled` 与 `groupContextStats: { recorded, rejected }`，只含当前运行期计数，不包含消息正文或群成员 ID。

近期背景同时记录群聊问答的用户提问和机器人成功发送的文字；机器人回复标注 `role: assistant`，并记录已确认发送的附件数量。自主接话明确标记当前新消息，背景中的旧问题不能替代当前输入。自主回复与被 @ 回复继续同一个群 Session，她自己的 assistant 历史会持续保留。缓存预算与 15 分钟有效期不变。

启用短期上下文开关不会自动启用自主回复，后者使用独立开关。原始短期上下文实现记录见 [WG-QQ-11 验收报告](../outputs/qq-impl/wg-qq-11-verification.md)，当前自主参与行为见[自主参与说明](QQ群聊自主参与.md)。
