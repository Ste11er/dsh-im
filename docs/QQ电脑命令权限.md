# QQ 电脑命令权限

QQ 机器人将电脑操作权限绑定到当前消息的真实 QQ 发送者。只有配置的 owner 身份能在该消息发起的回复回合使用终端、代码执行、文件操作或其他具备本机操作能力的工具；权限仍受 DSH 原有审批与沙箱控制。没有可核验 owner 身份时按非 owner 处理，`*` 不代表 owner。

其他成员仍可普通聊天、查看本群记忆、联网搜索和使用本地缓存的表情。表情附件只能返回本回合表情工具实际选中的文件。未 @ 的自主接话继续沿用只聊天、不执行电脑操作的既有规则；owner 如需发起电脑操作，应直接 @ 机器人或按现有权限使用私聊。

QQ 群和私聊标识分别保存在机器人配置的 `computerCommandOwners.group` 和 `computerCommandOwners.direct`；字段是明确的 QQ 平台标识，不接受通配符。账号字段 `ownerUserOpenid` 使用明确身份时，私聊电脑操作 owner 必须与它一致，配置冲突会报错。手动凭据重绑定保留这两个标识；二维码重新绑定若确认了不同的私聊 owner，会清除旧映射，避免旧 owner 保留群权限。未设置映射时，已验证的二维码绑定私聊 owner 可在私聊使用电脑工具，群聊不会自动推断身份。

本次部署依据此前用户确认的“群成员可 @，命令仅 owner，私聊仅 owner”，使用当前访问策略中各自唯一获准执行命令的群和私聊标识作为初始映射，并将原先的 `ownerUserOpenid: "*"` 修正为同一明确 owner。此后普通机器人命令权限的调整不会自动改变电脑操作的 owner；更换 owner 时需同步更新该映射。当前设置界面尚无此独立字段。

回合内的工具注册、模型提示和执行守卫都受限；聊天模型不会仅凭群友自称 owner、引用或历史文本获得电脑权限。限制依据的是本回合发言者身份；owner 自己发起的请求仍需辨别内容和 DSH 原有审批，并非对历史上下文进行可信认证。
