# QQ 人格基线

打开 IM 设置 → QQ → 对应机器人设置，可找到“人格基线”。可以启用或关闭、编辑人格与表达风格、恢复默认人格并保存。每个机器人独立保存，正文最多 4000 字符；关闭会保留正文，启用时正文不能为空。

默认人格侧重自然、亲切、有自己的看法，允许好奇、开心、吐槽和不同意见；减少客服套话、机械迎合、模板总结与反复追问。它仍依据当前消息和可用上下文交流，不虚构共同经历、记忆、现实身份或已经完成的行动。你可以按喜好改成更温柔、活泼、沉静或其他风格。

保存后无需新建会话或重启，后续 QQ 群聊和私聊回复会携带新的基线。已经开始的回复继续使用开始时的设置。重新绑定账号和服务重启保留设置；未配置的其他机器人默认关闭。

人格配置由经过身份验证的管理接口 `bot.persona.set` 保存，并由真实 QQ delivery consumer 绑定到当前 Session/Turn 后提供给独立的系统提示上下文。不会从群成员发言提取或修改人格，也不影响其他渠道、网页会话、访问策略或工具权限。设置不是每条聊天正文的一部分。

编辑中的草稿不会被后台状态刷新覆盖。保存失败会显示错误并保留草稿。恢复默认仅填入预设正文，仍需保存；关闭也需保存。系统自带预设在英文界面显示英文版本，自定义正文原样保留。

人格基线不生成历史记忆，不启用长期记忆，也不改变表情包“想用时就用”的设置。人格效果属于模型行为，需在真实聊天中观察，自动化检查验证的是设置和注入链路。
