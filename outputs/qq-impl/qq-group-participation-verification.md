# QQ 群聊自主参与与可调冷却验收

日期：2026-10-24。用户要求未 @ 时偶尔参与群聊，并明确要求冷却可调。已实现并部署，当前账号按 20% 候选概率、180 秒每群冷却启用。

## 闭合变更

- 新增 `groupParticipation: {enabled,probability,cooldownSeconds}` 每账号配置、控制器、运行时、QQ 卡片、客户端与管理接口 `bot.group-participation.set`。缺失默认关闭、20%、180 秒；合法概率 0–1，冷却正整数秒；非法值拒绝。保存、重启和重新绑定保留，不覆盖人格或模型设置。
- `QqGroupParticipation` 抽选候选、按群控制评估冷却及并发、取消与明确结果计数。冷却预算包含最终保持安静的候选。状态容量沿用短期群上下文的 100 群上限；不为腾出空间绕过有效冷却。收到 @ 会取消当前群自主评估并开始冷却，@ 的原处理链路照常。
- 普通未 @ 消息保持先通过访问策略并入短期上下文；只对新收集的允许群文字考虑自主回复。重复、机器人、斜杠命令、文件及纯图片不触发；繁忙任务、待审批/问题及活动菜单操作时不接话。关闭上下文或开关取消待处理候选。发送前重新核对门控、权限和工作区。
- 独立真实 Host Agent 在原生工具模式中判断自然接话或保持安静；仅允许两个表情工具，并用 scoped guard 将文件回传限制为本轮表情工具返回的路径。`run_code` 和通用操作工具不可用，缺少当前回合授权时拒绝工具执行。静默标记只按严格内部输出协议处理，混合或缺失结果属于错误，不发到群里；文件投递仍须经过权威工具登记，不解析正文路径发文件。
- 独立回合具有当前机器人模型（未指定则 Host 默认）、人格、表情开关、短期文字快照及 Session/Turn 归属。允许正常文字、配图或纯表情回复；群图片在自主评估中不下载，仅传已有缓存里的文字及图片数量。@ 图片问答保持原路径。
- 自主发送遵守暂停、预算、安静时段及 dry-run，最终按实际文字段数加图片数核算预算。主动插话不进入延迟群发队列；图片投递未确认不会算作已回复，未知结果不盲目重发。Agent/模型/发送失败保留明确统计和诊断，不当作“决定安静”。
- 面板可编辑概率和冷却，后台刷新保留草稿，失败保留输入并显示错误；提供中英文文案。候选、安静、接话与错误计数为进程内统计。说明见[QQ群聊自主参与](../../docs/QQ群聊自主参与.md)。
