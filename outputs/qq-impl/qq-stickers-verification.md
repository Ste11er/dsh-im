# QQ 语境表情回复验收

日期：2026-10-24。用户要求从指定 DeepSeek 表情站抓取表情，并由机器人按群聊语境决定使用时机和合适图片。已实现并部署，当前机器人已开启，长期记忆仍关闭。

## 实际变更

- 新增 `sticker-catalog.mjs`：从[站点公开源仓库](https://github.com/lmy414/bluedafeiyu)同步作品、历史分类、编辑与 ID 四份清单；同一 commit 内合并并筛选公开 DeepSeek meme。页面直连 403，使用站点明确公开链接的源数据，不执行远程脚本。
- 目录按需检查 24 小时时效，缓存持久化；同步失败且已有目录时明确返回陈旧状态。首次同步失败、损坏目录、损坏缓存、发布摘要不匹配均暴露失败。原图仅在选择后下载，遵循已有原图下载上限，校验格式、SHA-256 与公开摘要；老图无公开摘要时不虚构上游证明。
- 新增可信工具 `dsh_qq_sticker`：搜索情绪/场景 → 按 ID 获取缓存图片 → Agent 调用已有 `dsh_im_return_file`。工具渲染记录保留来源、ID、许可信息及摘要。模型正文中的路径不触发发图，不增加任意 URL 或群收件人参数。
- QQ bridge 通过 Harness 将渠道、群/私聊与开关传给实际 Session/Turn 的 delivery consumer，工具执行和行为提示都基于该真实回合归属检查。私聊、其他渠道、网页和关闭开关的 QQ 回复不可使用该工具。已有工具成功确认、原生图片发送及发送不确定状态语义复用原链路。
- 每机器人 `stickersEnabled` 独立开关，默认关闭。配置、控制器、运行时、管理 RPC、客户端和 UI 闭合更新。重启及重新绑定保留。Agent 按需使用，通常一张，不强制每条配图，不响应未 @ 消息。

说明：[QQ群聊表情包](../../docs/QQ群聊表情包.md)。
