# QQ 人格基线验收

日期：2026-10-24。用户要求新增可设置的人格基线，使聊天更自然。已实现、部署，并为当前机器人启用默认人格。

变更覆盖：每机器人 `persona: {enabled,text}` 配置 → 控制器/运行时/bridge → 已绑定当前 Session/Turn 的可信渠道上下文 → 独立 `dsh-im:qq-persona` 系统提示贡献。管理接口 `bot.persona.set` 与 QQ 设置卡片支持编辑、启用/关闭、恢复默认和保存。未配置账号默认关闭，当前账号按此次需求启用；重新绑定和重启保留。正文上限 4000 字符，启用时拒绝空白内容。

默认正文 240 字符：自然、亲切、放松、有自己的想法；减少客服腔、机械迎合、模板式总结和反复追问，同时不虚构经历、记忆和执行结果。基线应用于后续群聊/私聊回复，无需 /new；运行中回复使用开始时快照。其他渠道及无 QQ consumer 的网页回合不会获得该提示。人格不修改工具权限，不开启长期记忆，不改变自由使用表情的提示。

UI 使用已认证的管理链路；编辑草稿不被后台刷新覆盖；保存失败显示错误并保留草稿；恢复默认填入正文后仍需保存。新增中英文文案和默认模板显示，自定义正文不翻译。未新增依赖或后台服务。

新增 6 项回归：严格配置边界、系统提示按真实回合隔离与释放、RPC/配置/实时控制器/重新绑定、编辑与默认恢复、实际 QqRuntime→bridge 后续群聊及私聊请求更新、保存失败保留草稿。同步更新已有表情元数据测试，精确覆盖新增 persona 字段。测试通过不代表真实模型人格质量已经被测量。
