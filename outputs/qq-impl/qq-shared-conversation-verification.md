# QQ 群聊共享会话与自身发言上下文修复

日期：2026-10-25。

## 已确认根因

用户实测确认表情包已显示，但自主回复答非所问。现有实现每次自主回复新建临时 Host Session；短期缓存只有群友输入，没有机器人已经回答的内容；输入又仅有一整段历史片段，未单独标记当前新消息。这会让旧的“你叫什么”反复被当成当前问题，且没有她之前已经回答的证据。

## 变更与范围

- 保留独立无工具判断 Agent，名称改为 qq-group-judge-*。同意后调用渠道提供的 reply 回调，实际生成通过与被 @ 回复相同的 askInWorkspaceSession、state、group key 和工作区绑定，不再创建临时回复 Agent。
- 将当前消息放在独立 dsh_im_qq_current_message 标签中；背景快照取消息入站前的内容。判断提示和回复提示都要求只围绕当前新消息理解前文，不重复回答旧问题。
- 正常群问答也记录其用户提问；两条回复路径在确认文字/附件交付后记录机器人发言，标记 role=assistant。正常 Host Session 自身的 assistant 历史和近期判断上下文都包含机器人已经说过的话。附件仅记录已确认发送数量，不把登记当作已发送。沿用 20 条、8 KiB、15 分钟缓存预算。
- 共享 Agent 的自主回合按实际 claimed turn 临时切换原生工具呈现，限定本地表情、本轮所选表情回传、本群记忆查询。工具守卫保留到 Host 回合真正结束；等待方取消/关闭 consumer 不会解锁正在执行的回合。结束后恢复普通回合工具模式，取消只针对绑定的自主回合。部署卸载时取消尚未结束的自主回合。
- 设置说明、英文文案和群聊指南同步更新。没有修改访问策略、模型选择、人格、长期档案或群会话绑定，也没有合并来源不明的旧临时会话。
