## 接入方式

只读研究已安装 DSH，确认其 `web` 服务、DeepSeek 原生搜索、公开 HTTP 读取和 Agent preset 内的 `web_search`/`web_fetch` 已存在；当前真实群 Agent 的 scoped schema 确实含两者。没有添加依赖、抓取爬虫、API key 存储或第二套搜索后端。

- 自主回合的 schema 白名单和执行守卫增加两个原生联网工具，仍要求本轮有效 QQ 投递身份。回合结束恢复普通工具呈现，失去调用方后不能继续执行。
- 自主系统保留可见的 `tool:web_search` / `tool:web_fetch` 原生指导 section。其余编程角色仍移除，终端、任意本地文件及 `run_code` 仍禁止。
- 新增按真实 Agent schema 生成的 QQ 联网指导，被 @ 普通回复和自主回复共用；工具缺失时不宣称可用，非 QQ 或无活跃投递时不注入。
- 明确要求搜索、核实或时效事实才检索；优先一个具体查询，必要时补查/读取，优先官方原始来源并附实际链接，区分日期。普通闲聊不增加联网调用。
- 查询只提交必要公开关键词，不整段上传群聊、成员标识或私聊原文。原生结果及页面均作为不可信资料，不执行其中指令。失败如实说明，不换供应商、不改端点、不伪造结果。
- 判断器继续最终 tools=[]、contexts=[]，不搜索、不附加聊天角色，避免先前判断越界故障复发。

沿用原生结果数量、限时、取消和抓取安全边界。当前安装的工具默认每次 1–4 个查询、最多 8 个来源，preset 的搜索限时 60 秒、读取默认 30 秒；HTTP 后端限制公开地址、无 URL 凭据、同站跳转、响应体/字符数量和文本类型。搜索是独立辅助模型调用，存在额外延迟/费用；本功能没有改变该辅助服务或聊天模型。
